Test ki bhasha chuno · भाषा चुनें

Test ke beech bhi upar button se bhasha badal sakte ho. Test, marks aur rank ek hi rahte hain.

  1. Timer test start hote hi chalu ho jata hai; time khatam hone par test auto-submit ho jayega.
  2. Har question me ek hi option sahi hai. Galat answer par negative marking lagti hai, unattempted par 0.
  3. Upar subject tabs se Physics / Chemistry / Botany / Zoology ke beech jump kar sakte ho.
  4. Mark for Review se kisi question ko baad ke liye chhod sakte ho. Review ke liye marked answer bhi count hota hai.
  5. Test ke beech page refresh ya back mat karo, progress chala jayega.
  6. Test ke baad subject-wise, time-wise aur question-wise analysis explanation ke saath milega.
